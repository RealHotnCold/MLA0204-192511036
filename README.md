# MLA0204 – Machine Learning Laboratory

This repository contains the practical work, assignments, and capstone project completed for the **MLA0204 Machine Learning** course.

## What's included

- **Machine Learning practicals:** Jupyter notebooks covering algorithms and applications such as ID3, Candidate Elimination, K-Nearest Neighbours, Naive Bayes, Linear Regression, Perceptron, Artificial Neural Networks, and Expectation-Maximization.
- **Applied ML exercises:** Notebooks for credit-score classification, Iris classification, car-price prediction, house-price prediction, classification algorithm comparison, and future-sales prediction.
- **Assignments:** Course assignment PDFs are available in the `Assignment folder/` directory.
- **Capstone project:** The `Capstone-project/` directory contains the project report and presentation for *Algorithmic Stock Price Prediction*.
- **Capstone presentation material:** The repository also includes the capstone presentation video and presentation photo.

## Capstone project – Algorithmic Stock Price Prediction

The capstone explores the use of machine learning for stock-market price prediction and algorithmic trading, with MetaTrader 5 (MT5) as the trading platform.

The associated trading application is maintained in a separate repository:

**[Algo Stock Trading Engine – GitHub](https://github.com/RealHotnCold/Algo-Stock-Trading-Engine)**

Visit that repository for the application source code, setup instructions, requirements, and usage documentation.

## Opening the notebooks

1. Clone or download this repository.
2. Install Python and Jupyter Notebook, or use [Google Colab](https://colab.research.google.com/).
3. Open the required `.ipynb` file.
4. Install any libraries imported by that notebook if they are not already available.
5. Run the notebook cells in order.

Some notebooks may require datasets or files to be placed in the paths referenced by the notebook.
